# QUESTIONS — блокеры и решения к согласованию с человеком

Здесь копятся вопросы, которые нельзя решить угадыванием. Для каждого указан
предложенный дефолт, чтобы работа не блокировалась там, где дефолт безопасен.

Формат: **статус** — `OPEN` (ждёт человека) / `DEFAULTED` (идём по дефолту, можно
переопределить позже) / `RESOLVED` (человек подтвердил).

---

## Q1 — Движок Hysteria2: `sing-box` vs бинарник `hysteria`
**Статус:** `DEFAULTED` → `sing-box`.
**Почему дефолт:** единый JSON-формат конфигов, активная поддержка, один движок под
будущие протоколы (SPEC §5). Реестр протоколов абстрагирует движок, так что смена
позже не трогает схему БД. Не блокирует Фазы 0–1 (мок-фронт движок не запускает).
**Нужно от человека:** подтвердить `sing-box` либо выбрать `hysteria`.

## Q2 — Стратегия TLS для Hysteria2
**Статус:** `DEFAULTED` → самоподписанный серт на ноде + `insecure=1` в клиентском URI.
**Почему дефолт:** проще всего для личного использования, не требует валидного домена
на каждой ноде (SPEC §5, §7). Альтернативы: реальный серт / ACME на ноде.
**Нужно от человека:** подтвердить дефолт либо выбрать реальный серт/ACME.

## Q3 — Установлен ли движок Hysteria2 на нодах заранее
**Статус:** `DEFAULTED` → считаем, что движок (sing-box/hysteria) уже установлен на
ноде; панель управляет только конфигом и рестартом (SPEC §5). Установка движка — вне
SSH-конфиг-механизма MVP.
**Нужно от человека:** подтвердить, либо сказать, что панель должна помогать с установкой.

## Q4 — Docker не установлен в среде разработки
**Статус:** `OPEN` (не блокирует Фазы 0–1).
**Контекст:** в текущей среде нет `docker`/`docker compose`/`colima`. Это понадобится
с Фазы 2: локальные dockerized-ноды `test/xray-node` и `test/hysteria-node`, а также
`docker compose up` для полного локального запуска (Фаза 7) и деплоя (Фаза 8).
**Нужно от человека:** установить Docker Desktop или Colima до Фазы 2. Фазы 0–1
(мок-фронт) выполняются без Docker — только Node/npm.

## Q5 — Git remote для финального push
**Статус:** `OPEN` (нужно только к Фазе 9).
**Нужно от человека:** URL удалённого репозитория и разрешение на `git push` (Фаза 9).

## Q6 — Данные деплоя (Фаза 8)
**Статус:** `OPEN` (нужно только к Фазе 8).
**Нужно от человека в момент Фазы 8:** IP/хост VPS, SSH login/pass (и/или ключ), домен
с A-записью на VPS. Данные используются только в рамках сессии, не коммитятся.
